## 2. Genuine two-person NCALayer sequence

Required: **two eligible personal TEST signing certificates belonging to
different people**, a current strict official TEST OCSP verifier, and NCALayer
on the local Mac. A second account with the same personal certificate is not a
second person. Organization containers cannot substitute in this personal-only
stand. A public `.cer/.crt` can help inspect eligibility but cannot itself sign.

When material and browser access are available, start an explicitly signed,
fresh private stand with the official SDK following the signed launcher
procedure. Do not silently downgrade it to unsigned or seed MODEL identity data.

1. Each fresh TEST participant separately binds their own eligible personal
   certificate over the exact enrollment bytes. Confirm distinct opaque bindings
   privately; never publish subjects, IIN/BIN or keys.
2. Invite the counterpart. Both inspect the same terms version, document manifest
   and snapshot. Seller signs offer, buyer agreement, seller handover, buyer
   acceptance (or a separate dispute fixture), each via its own fresh instruction.
3. Compare one durable protected receipt to each event. Exact CMS retry must
   return historical receipt/event without new verification or a duplicate write.
4. Wrong person/role, stale terms or manifest, altered bytes, expired session,
   revoked certificate and direct unsigned event must refuse without a new row.
5. Close/restart/login and read the same records back. Exports remain public
   receipt metadata only; feedback remains explicitly unsigned.

Actual NCALayer consent, genuine SDK verification, HTTP persistence and human
acceptance are separate evidence levels. Do not infer any one from MODEL tests.
